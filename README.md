# daily-brief-books-media

Streaming mirror for The Daily Brief Bookshelf chapter audio. The canonical files are release assets
in [carl-m-healy/daily-brief](https://github.com/carl-m-healy/daily-brief) under tags `books-<slug>`;
this repo's Pages site serves them as `audio/mpeg` with Range support so the reader can seek.

Deployed from a workflow artifact, so nothing is committed here. Owned by the books module of
`/workspace/xbrief` — see `BOOKS.md` there. Nothing on this site is linked from anywhere public.
